# Captures d'écran du README

Ce dossier accueille les captures d'écran **réelles** de Yunagi utilisées dans le [README principal](../../../README.md).

Aucune capture n'y figure encore : lors de la rédaction du README, l'application et le site de présentation n'étaient pas joignables depuis l'environnement de travail, et les sources consultées n'en contenaient pas. Aucune fausse capture ni maquette ne doit être déposée ici.

## Recommandations

- Utiliser un compte de démonstration : **aucune donnée personnelle** (e-mail, pseudo réel d'un membre, contenu privé) ne doit apparaître.
- Format PNG ou WebP, largeur ≈ 1280 px pour le bureau, ≈ 390 px pour le mobile.
- Une fois les fichiers déposés, les insérer dans la section « Galerie » du README et en tête des sections concernées, avec une courte légende.
